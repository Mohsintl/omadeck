# Security Policy

OmaDeck can type and run actions on your desktop, so security reports are welcome.

## Reporting a problem

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/Mohsintl/omadeck/security/advisories/new), not in a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it.

## Supported versions

Only the latest release gets security fixes.

## What's in scope

OmaDeck is designed for a network you trust. The README's [security guide](README.md#-network-security--privacy-guide) lists its protections and known limits. Please report a way around a listed protection, even if it seems minor. Items already listed as known limits don't need a report.
